## Change
`eval_niah.py` `score()`: greedy decoding replaces both teacher-forced chains. Forward 1 is still teacher-forced on
prompt + " NNNNN" (gives log p(" NNNNN") and greedy token 1); then every sample not yet decided takes one greedy
step per forward, up to 8 tokens. A sample is decided when its text matches `\s*\d+\D` (correct iff the digits equal
the needle) or its first non-space character is not a digit (wrong). This is exactly gen_check's rule
(`re.match(r'\s*(\d+)')` on 8 greedy tokens), so gen_check now checks batched vs one-at-a-time decoding (agreement
should be 20/20 up to bf16 batch-shape ties). Removed: stage 2, `logp_ws`, `first_ws_rate`. Added per sample `gen`
text and `n_gen`; per length `mean_n_gen`. Samples identical to e002/e003 (seed (1234, L)); n per length 300 -> 200
(the backlog minimum, to fit the 5 GPU-h ceiling; SE <= 3.5 pt).
Cost: forward 1 plus ~1.3 greedy forwards per sample (e003 smoke: ~all samples start with "\n", ~25 % continue with
digits at 2k, fewer at length) = ~1.15x e003 per sample. e003 smoke time per 20 samples summed over the four
lengths: softmax 42 s, ASEntmax 62 s, q3/d2 115 s. At 200/length x 1.15: softmax ~0.13 h, ASEntmax ~0.2 h,
Stieltjes ~0.37 h per checkpoint -> 2 x 0.13 + 2 x 0.2 + 6 x 0.37 = ~2.9 GPU-h for ten, plus ~0.1 smoke.
Walltime 1:30 unchanged (largest task ~0.4 h). Smoke gate: batched vs single agreement >= 19/20 per row and greedy
correct at 2k equal to the e003 gen_check counts (5/7/5) within 1.
